# 金手指系统（GoldenFinger）

SillyTavern 第三方扩展：网络小说式的「金手指系统」玩法。为当前聊天绑定一个系统（签到系统 / 修仙系统 / 神级选择系统 / 无限流系统 / 败家子系统，或自建），系统**异步调用 API 发布任务**，结算奖励、升级，并把系统状态**注入提示词**给正文 AI 参考，让 AI 在剧情里感知到系统的存在。

基于 [tavern_extension_template](https://github.com/StageDog/tavern_extension_template)：TypeScript + Vue 3 SFC + Pinia + Zod + Vite。

## 功能

- **多个系统可选**：5 个内置系统（各有独立人格、货币、等级称号、任务风格与主题色），支持在设置里创建自定义系统（名称/图标/主题色/货币/商店/等级/系统设定/任务风格）。
- **六标签游戏面板**：首页（状态总览+快捷操作）/ 任务 / 商店 / 背包 / 日志 / 设置，可拖拽、记忆位置。
- **异步 API 发布任务**：点击「发布新任务」或开启自动发布后，系统会根据最近剧情异步调用 API 生成新任务（严格 JSON 契约 + 容错解析）。任务生成可跟随酒馆当前连接，也可配置独立的**副 API**（OpenAI 兼容端点，用小模型省钱，内置服务商预设与「拉取模型列表」连通测试）。
- **系统商店**：首次进店免费开张，AI 按系统气质与剧情氛围生成一批商品（普通/稀有/传说三档稀有度配色）；「换一批」消耗货币重新进货；购买即时扣款入包，道具会随背包注入给正文 AI 在剧情中使用。
- **任务判定与奖励结算**：正文 AI 依注入的规则在回复末尾输出判定标记（`[任务完成:T001]` / `[任务失败:T001]`），插件监听消息自动结算：货币入账、物品入包、经验累积、自动升级（可配置结算后自动移除标记）。也可在面板里手动结算。
- **提示词可见**：设置页内实时预览当前注入给正文 AI 的完整文本（含 token 数与一键复制），注入位置与深度可调。
- **每个聊天独立存档**：游玩状态存在聊天元数据里，随聊天文件走；换聊天自动切换，互不干扰。

## 安装

将本仓库克隆到 `SillyTavern/public/scripts/extensions/third-party/` 下，重启酒馆（或刷新页面）即可：

```bash
cd SillyTavern/public/scripts/extensions/third-party
git clone https://github.com/Junwu-Git/GoldenFinger.git
```

## 使用

1. 打开魔棒（扩展菜单）里的「金手指」，或扩展设置里的「打开/关闭系统面板」。
2. 在面板里选一个系统绑定到当前聊天。
3. 「任务」页点「发布新任务」，系统会异步生成一个贴合剧情的任务；按提示推进剧情即可。
4. 任务达成时 AI 会在回复末尾输出判定标记，插件自动结算奖励并升级（需要正文 AI 遵循注入的判定规则；漏判时可在任务页手动结算）。
5. 「商店」页首次进入免费开张，用货币购买道具（会进背包并注入给正文 AI）；「换一批」消耗货币重新进货。
6. 「设置」页配置任务生成 API（跟随酒馆连接或独立副 API）、注入位置/深度、自动发布，并可实时预览注入给正文 AI 的提示词。

## 任务生成 API

- **跟随酒馆当前连接**（默认）：走酒馆的 `generateRaw`，无需额外配置。
- **副 API**：填 OpenAI 兼容的地址 + 模型（可选密钥），任务与商店生成直连该端点，与正文 API 解耦。内置常用服务商预设，装了酒馆助手时可用「拉取模型」一键填模型兼测连通。

## 开发

```bash
pnpm install
pnpm build       # 产物 → dist/index.js + dist/index.css
pnpm watch       # 持续打包（刷新酒馆页面生效）
pnpm typecheck   # vue-tsc --noEmit
pnpm lint
```
